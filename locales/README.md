# Interface Languages

Fusion Studio keeps its product name and exact English subtitle, *A community toolkit for MITRE ATT&CK® and ATLAS*, in both languages. About/Exit labels are translated; document filenames remain user content. `app_identity.py` supplies the runtime identity; root README documents its absolute-input-path and two-stage startup reporting.

Framework file IO dialogs (`framework_dialog.py`) and Navigator import checkboxes include Traditional Chinese labels. The ATT&CK/ATLAS boolean choices stay canonical and default to both checked independently of language. Partial-output and new-Workplace import explanations are translated, while the absolute selected file path is retained. `audit_framework_io.py` checks the real dialog and bilingual choices; its report/preview paths and the full operation flow are in the root README.

ATLAS Workplace adds localized navigation, peer matrix tabs, close/reopen menus, selected-framework toggles and annotation/selection buttons. Native ATLAS technique names, IDs, descriptions and case-study content remain source text. The rail uses two-line ATLAS Mitigations/Case Studies labels; translation keys preserve those line breaks. Language changes leave framework IDs and independent document selections intact. The root README documents the module and save/recovery flow; `audit_atlas.py` uses isolated settings for bilingual preview checks.

English (`en`) is the default. `zh_TW.json` contains Taiwan Traditional Chinese display translations. Choose **Settings → Language** to switch immediately; the selection is saved as `interface/language` in the absolute `settings_path` announced by the application. The Manual follows the same preference and opens equivalent bundled guides.

`localization.py` reads the catalog before building the interface and reports input paths and staged progress. It tracks original UI strings separately, updates menus/labels/buttons/tooltips/placeholders/tabs/headers, and paints translated combo choices through a delegate while retaining canonical `currentText`, `currentData`, and signals. Document tabs are identified by their stable IDs so user filenames are never translated. User input editors, comments, JSON, formulas and original ATT&CK objects are not rewritten. Designated rich-text browsers translate UI text nodes, preserving attributes and code blocks. Qt's bundled `qtbase_zh_TW` translator supplies standard dialog buttons where available.

Qt file dialogs are used for consistent application-language presentation. UI-only status columns use a paint delegate; editable table cells and source data columns retain their original values. Known menu paths in Traditional Chinese guides are localized while code blocks remain literal. A missing/invalid catalog leaves English usable and prevents saving an unusable Chinese preference. The language event filter detaches before application shutdown, so deferred refreshes cannot touch destroyed widgets.

Catalog keys may include named placeholders such as `Selected Techniques ({count})`; translation preserves captured values. Keep placeholders, identifiers and URLs intact. The English source is always retained for switching back. Adding a guide requires matching `_en.md` and `+_zh.md` files, matching feature-link IDs, and updates to `manual/README.md`. Localization is a presentation preference, separate from saved Studio document data.

NAV-025 adds SVG theme labels and its export-only hint. The Light/Dark combo retains canonical `light`/`dark` item data during language changes; localized labels do not enter layer data or alter the application palette. SVG projection and progress workflow are described in the root README and paired SVG theme guides.

NAV-026 adds paper-size, Portrait/Landscape and Custom labels. Choice item data stays custom/letter/legal/small/medium/large and portrait/landscape during translation; labels do not change physical lengths, export options or saved layers. The root README and paired paper-size manuals document conversion and operation progress.
