# SVG 淺色與深色主題

選擇 **Navigator → Export matrix SVG…（匯出矩陣 SVG）**並指定位置，再到 **設定 → 影像與標頭區 → SVG 主題**，選擇「深色」或「淺色」。初始為深色，延續既有預設。主題只保留在本次匯出視窗，重開視窗會回到深色。

## 預覽與匯出

1. 開啟匯出視窗前，先設定矩陣的平台、搜尋、色彩顯示與疊圖檢視。
2. 淺色使用適合淺底報告的白色畫布；深色使用深色畫布。
3. 按「預覽 SVG · 不寫入檔案」，預覽分頁會顯示真正的 SVG 內容。
4. 檢查標頭、技術、停用項目與圖例；既有尺寸、字型、框線、圖例及子技術設定仍可使用。
5. 按「匯出 SVG」。設定與擷取畫面相同時，預覽和輸出 SVG 的位元組完全相同。
6. 要輸出另一主題，回設定切換後重新預覽／匯出。修改設定後，狀態列會提醒舊預覽須更新；再按預覽即可看到新主題。

SVG 主題只改變輸出呈現，不編輯 TTP 選取、註記、手動色、分數、漸層、Tactic 背景、儲存狀態或程式目前的深色介面。主題不寫入 Studio／Navigator 圖層 JSON，也不影響單圖層／多圖層 Excel。整個程式的明暗主題仍是另一項功能。

## 哪些內容隨主題改變

| 元素 | 行為 |
| --- | --- |
| 畫布、標頭、中性格子 | 使用該主題的背景與可讀文字顏色。 |
| 不透明手動技術色 | 保留原本 RGB；文字依背景選用黑色或白色。 |
| 透明分數／彙總漸層 | 保留內插得到的原始 RGBA，再對該主題的中性底合成；完全透明時呈現中性底色。 |
| 多圖層疊色 | 每個有效來源先對該主題底色合成，再使用既有等權重混色；來源順序、各來源顯示開關與零透明度排除規則不變。 |
| 停用技術 | 使用可區分的灰底及可讀灰字。隱藏停用仍會移除；隱藏色彩則讓格子中性化，懸停內容仍保有啟用狀態。 |
| Tactic 背景 | 保留明確指定的顏色與對比文字；Mini 的標頭底色隨 SVG 主題變化。 |
| 圖例 | 面板及文字隨主題變化，透明色票對實際面板底色合成；淺色增加色票邊框。顯示／固定／獨立定位設定仍各自有效。 |
| 註記指示線 | 保留設定的顏色；淺色增加對比襯線，讓淡色指示仍可見。 |
| 儲存格框線 | 保留使用者設定的框線色，可依需求自行調整。 |

透明顏色在淺色與深色下外觀不同，是背景變化後的正常合成結果；原始漸層色階、分數及手動色並未改寫。圖層 JSON 仍保存可編輯的原始數值。

兩個主題皆支援 Flat／Side／Mini，包含黑白格子、原始／彙總分數、註記指示、Mini 選取框及中英文原文。預覽與匯出使用同一繪製流程及設定。很小的畫布仍會縮小文字。[紙張預設與方向](svg_paper+_zh.md)現已可用，手動字級及自動適字仍是另外的待辦。

## 範例

若分數漸層為 0–100、顏色從 `#ff000000` 到 `#ff0000ff`，50 分會得到原始 `#ff000080`。在淺色中性底 `#f2f4f5` 上，格子呈現 `#f97a7a`；在深色中性底 `#222526` 上則是 `#911213`。完全不透明的黑格在兩個主題都維持黑色、搭配白字；白格則維持黑字。

製作報告時可將相同矩陣分別輸出為既有 `examples` 目錄內的 `matrix-light.svg` 與 `matrix-dark.svg`，兩次之間切換主題即可，不必複製圖層。

程式呼叫範例，須在專案環境中執行：

```python
from matrix_exports import export_matrix

# document 為已載入的 TTPDocument，report 為進度回呼。
export_matrix(document, output_path, 'svg', report,
              svg_options={'theme': 'light'})
```

`theme` 僅接受 `light`／`dark`，省略時預設深色。無效型別／值會在發布前拒絕，其他既有設定可一併指定。其餘控制項詳見[進階設定與 Excel 手冊](aggregation_and_exports+_zh.md)。

## 程式流程與驗證

預覽先明示記憶體輸入／無輸出檔，再顯示「SVG Preview 1/3 驗證 → 2/3 繪製所選主題 → 3/3 完成」。匯出先顯示目的／暫存檔絕對路徑，再依「Matrix Export 1/4 投影 → 2/4 繪製所選主題 → 3/4 寫入 → 4/4 原子發布」進行。驗證錯誤、取消或發布失敗保留原輸出並清除暫存檔。

程式流程：`export_dialogs.py` 擷取主題標準值 → `layer_analysis_dialogs.py` 凍結設定並協調背景預覽／匯出 → `matrix_exports.py` 繪製 Flat／Side／Mini → `svg_export.py` 套用進階畫布／標頭／圖例主題 → `svg_themes.py` 投影 SVG 專用配色及透明合成。`navigator_visuals.py` 的唯讀外觀資料提供原始 RGBA，原生矩陣外觀保持既有規則。各模組於根目錄 README 記錄流程。

在專案根目錄執行：

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
& '.\.venv\Scripts\python.exe' -B '.\audit_svg_themes.py'
```

離線驗證先顯示輸入／輸出絕對路徑，再測試快照 → 三排版／雙主題的實際像素與文字對比 → 標頭／圖例／隱藏色彩／彙總 → 疊色 → 原生雙語設定／預覽與輸出完全一致 → 無效輸入／失敗／取消及真實 Enterprise-Mobile-ICS → 發布 `artifacts/svg-themes/audit.json`。SVG／PNG 範例有 `flat-light`、`flat-dark`、`side-light`、`side-dark`、`mini-light`、`mini-dark`，原生截圖有 `settings-en.png`、`settings-zh.png` 及雙主題預覽。已登錄 `scripts/audit_linux.py`，登錄本身不代表本輪另通過原生 Linux 驗證。
