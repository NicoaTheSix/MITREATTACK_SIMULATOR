# CAR integration acceptance evidence

Inputs are the application's absolute `data/car/source.json` / original members and `data/attack` cache. All CAR audit settings, recovery files, fixtures, exported JSON/CSV and screenshots are confined to this directory. Root user settings/session and official active/latest pointers are checked byte-for-byte before/after the CAR run.

Run from the project root:

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe -B audit_car_integration.py
```

The four processing stages are fixed source/schema/generator equivalence → real Qt sorting/filters/links/icons/inclusion → Save/Open/selective scopes/CSV/Navigator/recovery → bilingual UI/failure/restart/offline checks and report. Absolute input/output paths precede processing; in-memory actions explicitly say so. Existing fixture files in this directory are regenerated by the audit; it resets its own settings/recovery fixtures before startup, never the user's session.
